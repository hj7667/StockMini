# StockMini

미니 재고 관리 프로그램 — C#/.NET 학습 사이드 프로젝트

## 프로젝트 개요

WPF와 Entity Framework Core를 이용해 만드는 로컬 재고 관리 애플리케이션입니다.  C#/.NET 실무 감각을 키우기 위한 목적으로 시작했습니다.

## 학습 목표

- C# 언어와 .NET 런타임의 기본 동작 원리 이해
- WPF와 MVVM 패턴을 이용한 화면 구성 방식 익히기
- 리액트에서 다뤘던 컴포넌트/상태 개념을 WPF의 Binding/Command 개념과 연결해서 이해하기
- Entity Framework Core를 이용한 데이터베이스 연동 (모델 설계, DbContext, 마이그레이션)
- MS SQL Server 환경에서 실제 테이블을 만들고 CRUD를 직접 구현해보기
- 실무 재고관리 시스템의 축소판을 만들어보며 도메인 구조 이해도 높이기

## 기술 스택

- C#
- WPF (.NET)
- Entity Framework Core
- SQL Server Express

## 주요 기능

- 품목 등록 / 조회
- 재고 입고 / 출고 (예정)
- 품목 검색 및 필터 (예정)
- 재고 부족 알림 표시 (예정)
